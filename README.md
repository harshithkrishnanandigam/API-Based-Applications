# API-Based Python Applications

A collection of lightweight, modular Python applications that interface with external REST APIs to fetch real-time data, parse JSON payloads, and handle runtime exceptions gracefully.

---

## 🛠️ Included Applications

* **`weather_app.py`**: Fetches live temperature and weather condition data for any given city.
* **`news_app.py`**: Aggregates top news headlines filtered by category or topic.
* **`currency_converter.py`**: Converts amounts between global currencies using real-time foreign exchange rates.

---

## 🚀 How to Run Locally

### Prerequisites
Make sure you have [Python 3.x](https://www.python.org/downloads/) installed along with the `requests` library:

```bash
pip install requests
```
Running a script
```bash
python weather_app.py
python news_app.py
python currency_converter.py
